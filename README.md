# Starbucks - Interatividade com JavaScript

Este projeto é uma interface interativa inspirada na marca Starbucks, desenvolvida com HTML, CSS e JavaScript. Ele permite ao usuário visualizar diferentes copos de Starbucks e mudar a cor de fundo ao clicar nas imagens dos copos, refletindo a escolha. A página apresenta uma animação de interação, onde ao selecionar um copo, o produto mostrado na tela é alterado, e o fundo da página também muda para refletir a cor do copo selecionado.

Tecnologias utilizadas:
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Recursos:
<ul>
  <li>Personalização dinâmica da imagem e cor de fundo</li>
  <li>Efeito de hover nas miniaturas dos copos</li>
</ul>

Este projeto foi desenvolvido para praticar a manipulação de DOM com JavaScript e a criação de interfaces dinâmicas.
